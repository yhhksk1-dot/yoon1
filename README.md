# 안동시 외국인 관광 가이드 웹앱 (Visit Andong)

경상북도 안동시를 방문하는 외국인 관광객들을 위해 제작된 **무설치·단독 실행형 반응형 웹 애플리케이션**입니다.

---

## 🚀 바로 실행하는 방법 (No Install / No Server)

별도의 파이썬(Python), Node.js, 웹 서버 프로그램 설치가 전혀 필요하지 않습니다.

1. 파일 탐색기에서 프로젝트 폴더를 엽니다:
   ```text
   c:\Users\user\Desktop\antigravity
   ```
2. **`index.html`** 파일을 **더블 클릭**합니다.
3. 기본 웹 브라우저(Google Chrome, Microsoft Edge, Safari 등)에서 즉시 실행됩니다!

---

## 🌟 주요 기능 및 구성

### 1. 🏛️ 유네스코 및 핵심 관광지 둘러보기 (Attractions)
- **하회마을 (Hahoe Folk Village)**, **병산서원 (Byeongsan Seowon)**, **도산서원 (Dosan Seowon)**, **봉정사 (Bongjeongsa)**, **월영교 (Woryeonggyo)** 등 안동의 대표 명소 수록.
- **실시간 검색 및 카테고리 필터링**: UNESCO, 자연경관, 미식, 전통체험, 야경 등으로 즉시 분류.
- **상세 모달 팝업**:
  - 영문 해설 및 운영시간, 입장료, 대중교통 팁
  - **한국어 주소 원클릭 복사**: 택시 기사님에게 보여주거나 내비게이션 검색에 활용 가능
  - **구글 지도 (Google Maps) 다이렉트 연결 버튼**

### 2. 🍲 안동 대표 미식 가이드 (Food & Gourmet)
- **안동찜닭 (Andong Jjimdak)**, **헛제삿밥 (Heotjesatbap)**, **안동 간고등어**, **전통 안동소주**, **맘모스 베이커리 크림치즈빵**
- 외국인을 위한 맵기 단계 안내, 알레르기/식단 정보(베지터리언 팁), 주문 팁 수록.

### 3. 🗓️ 추천 여행 일정 코스 (Itineraries)
- **1일 핵심 코스 (Soul of Joseon Express)**: KTX 안동역 도착부터 하회마을, 탈놀이, 찜닭골목, 월영교 야경까지
- **2일 힐링 코스 (Deep Cultural Immersion)**: 봉정사, 한옥스테이, 부용대 일몰, 도산서원 등 여유로운 코스

### 4. 🗣️ 여행자 필수 한국어 플래시카드 & 발음 듣기 (Audio Phrases)
- 브라우저 내장 Web Speech API 기반 **원어민 발음 듣기 버튼(스피커 아이콘)** 제공 (외부 서버 필요 없음).
- "안 맵게 해주세요", "안동역으로 가주세요", "얼마예요?", "도와주세요" 등 실전 필수 표현과 로마자 발음 표기.

### 5. 🚆 대중교통 가이드 & 환율 계산기 (Transport & Converter)
- 서울 청량리에서 KTX-이음으로 안동역 오는 법 (약 2시간 소요).
- 하회마을행 210번 시내버스 정보 및 택시 이용 요령.
- 원화(KRW)를 달러(USD), 유로(EUR), 엔화(JPY), 위안화(CNY)로 즉시 계산해 볼 수 있는 계산기.

### 6. 🎒 나만의 여행 일정 플래너 (My Trip)
- 마음에 드는 명소 카드에서 하트(♡) 버튼을 누르면 나만의 일정 목록에 자동 저장 (`localStorage` 영구 보관).
- 우측 상단 가방/하트 아이콘을 눌러 담아둔 목록을 확인하고, **"일정 텍스트 복사(Copy Itinerary)"** 로 간편하게 메모나 메신저에 공유 가능.

### 7. 🌗 다크 모드 & 다국어 전환
- 눈이 편안한 라이트/다크 테마 토글.
- 우측 상단 `KR / EN` 버튼으로 한국어 및 영문 뷰 간편 전환 지원.
